검색 결과

⚙️ 전체 386편 검색 활성화 (무료 API 키 1회 설정)

유튜브는 외부 사이트가 채널 영상 목록을 직접 읽는 것을 허용하지 않습니다. 구글이 무료로 제공하는 YouTube Data API 키를 한 번만 넣으면, 이 사이트가 채널의 전체 영상 목록을 받아 브라우저에 저장하고 그 뒤로는 즉시 검색됩니다.

발급 방법 (약 2분, 무료)

  1. Google Cloud Console에서 새 프로젝트를 만듭니다.
  2. YouTube Data API v3 페이지에서 사용을 누릅니다.
  3. 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키를 선택합니다.
  4. 생성된 키(AIza…)를 복사해 아래에 붙여 넣습니다.
🔒 키는 이 브라우저의 localStorage에만 저장되며 GitHub 저장소나 외부 서버로 전송되지 않습니다. 구글 콘솔에서 키 제한을 HTTP 리퍼러로 이 사이트 주소만 허용하도록 설정하면 더 안전합니다. 영상 목록 전체를 받는 데 드는 일일 할당량은 약 8 단위(무료 한도 10,000 단위)입니다.
비공식 검색 도구입니다. 모든 영상의 저작권과 소유권은 채널 운영자 Elena Prieto(Tu escuela de español)에게 있으며, 재생은 유튜브 공식 플레이어를 통해 이루어집니다.
